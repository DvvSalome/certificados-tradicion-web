# Assets de marca — Certitradición

Color de marca: **morado `#774b78`** · acento **lima `#a3e635`**. Logo = sello (documento + pluma firmando).

| Archivo | Uso |
|---|---|
| `perfil-whatsapp-morado.png` | **Foto de perfil de WhatsApp / Instagram / Facebook.** Cuadrado 1000×1000, sello blanco sobre morado, centrado a prueba de recorte circular. |
| `icono-morado.png` | Ícono (sello) morado sobre transparente — para fondos claros. |
| `icono-blanco.png` | Ícono (sello) blanco sobre transparente — para fondos oscuros. |
| `logo-horizontal-oscuro.png` | Logo completo (sello + nombre) texto oscuro, fondo transparente — para documentos/fondos claros. |
| `logo-horizontal-morado.png` | Logo completo sobre morado (banner) — para portadas, cabeceras, redes. |

`../logo.png` es la versión cuadrada del ícono sobre blanco que usa el schema del sitio (Organization logo).

Para descargarlos al teléfono: abre la URL, p. ej. `https://certitradicion.com/brand/perfil-whatsapp-morado.png` y guarda la imagen.
